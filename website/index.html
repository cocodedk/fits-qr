What the QR actually contains

No shortlink, no redirect, no server in the middle. The code encodes a vCard 3.0 in plain UTF-8, generated on your device. This is the exact text the card on the left is showing right now.

BEGIN:VCARD
VERSION:3.0
N:Salameh;Bassil;;;
FN:Bassil Salameh
ORG:FITS - Framework for IT Security
TITLE:CEO
TEL;TYPE=WORK,VOICE:+45 22 547 547
EMAIL;TYPE=WORK,INTERNET:fits@l7consulting.dk
ADR;TYPE=WORK:;;Københavnsvej 19B;Roskilde;;4000;Denmark
URL:https://fits.dk
END:VCARD

No permissions, no network

The app asks for nothing and talks to nobody. QR codes are generated on-device with ZXing, so it works in airplane mode.

A real vCard, not a link

Name, role, organisation, work phone, work email, the Roskilde office address and fits.dk — all inside the code itself.

Yours to read and rebuild

Apache-2.0, Kotlin and Jetpack Compose. Change a contact in one file and the QR regenerates from it.

Install it

The APK is built and signed by GitHub Actions on every release, so what you download is what the workflow produced from this source.

  1. Download the APK

    Grab FITS-QR.apk from the latest release on GitHub.

  2. Allow the install

    Android will ask once whether to trust an app from outside the Play Store. This is the normal prompt for a sideloaded APK.

  3. Open and swipe

    Swipe left or right between the three cards. Hand your phone over, or let someone scan straight off your screen.
